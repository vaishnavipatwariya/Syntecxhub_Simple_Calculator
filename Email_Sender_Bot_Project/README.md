# Email Sender Bot - Syntecxhub Internship

## Features
- Sends automated emails
- CSV recipient list
- Personalized messages
- Retry logic
- Gmail SMTP (App Password required)
- Attachment support

## How to Run
1. Install dependency:
   pip install pandas
2. Update email + app password in email_sender.py
3. Run:
   python email_sender.py
